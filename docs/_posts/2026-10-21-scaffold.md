Scaffold is a code generation platform built with Spring Boot 3.4 and Java 21. You describe a microservice by name, entity attributes and options, and it generates a complete project: entity, DTOs, a MapStruct mapper, service, controller, tests, a Dockerfile and a docker-compose file.

The generator renders FreeMarker templates, keeps an application registry in a REST API, and can start and stop the generated services while a port registry assigns their ports.

**Stack:** Java 21, Spring Boot 3.4.1, Spring Data JPA, FreeMarker, MapStruct, Lombok, H2, Maven.

Database credentials are read from environment variables and are never stored in the repository. The setup, endpoints and configuration are in the [project README](https://github.com/josesaid/scaffold#readme). The project page is [here](https://josesaid.github.io/scaffold/).

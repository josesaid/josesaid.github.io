A Spring Boot example that shows how to build **semantic search** over PDF documents using **Spring AI**, **OpenAI embeddings** and **PostgreSQL + pgvector** as the vector store. It also exposes a simple chat endpoint backed by an OpenAI chat model.

Full setup, endpoints and configuration are in the [project README](https://github.com/josesaid/api-spring-ai-simple-vector-store-pgvector-openai-v1#readme). The project page is [here](https://josesaid.github.io/api-spring-ai-simple-vector-store-pgvector-openai-v1/).

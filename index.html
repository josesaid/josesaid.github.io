shirts-agent

Java 21 · Spring Boot 3.5.6 · Spring AI 1.1.8 · OpenAI gpt-4o-mini · Maven

A Spring AI agent that recommends a t-shirt in a requested color. The model calls an annotated @Tool method over an in-memory catalog and returns a structured result. Invalid input returns HTTP 400 before the model is called.

taller-spring-security

Java 25 · Spring Boot 4.1.1 · Spring Data JPA · H2 · MapStruct · Maven

A course platform REST API for a Spring Security workshop. The baseline is intentionally unsecured. The roadmap adds JWT authentication, a SecurityFilterChain, role and ownership checks with @PreAuthorize, and JSON 401/403 responses.
